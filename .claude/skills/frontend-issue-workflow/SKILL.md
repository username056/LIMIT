# 프론트엔드 이슈 처리

## 목적

Vue 변경을 공통 API 계약과 사용자 상태 흐름에 맞게 구현하고 검증한다.

## 먼저 읽을 근거

1. 루트와 `frontend/AGENTS.md`
2. 이슈의 요구사항과 완료 조건
3. 관련 feature, 공통 컴포넌트, API client, 인접 테스트
4. 필요한 경우에만 `docs/api`와 디자인 근거

## 작업 순서

1. 화면 상태와 API 계약을 확인한다.
2. 운영 URL과 Secret을 하드코딩하지 않고 환경변수를 사용한다.
3. 로딩·성공·빈 결과·오류 상태를 구현한다.
4. 사용자 동작과 실패 경로 테스트를 추가한다.
5. `npm run lint`, `npm run test`, `npm run build`를 실행한다.
6. 가능한 경우 실제 화면과 콘솔 오류를 확인한다.

## 산출물과 완료 기준

변경 파일과 이유, 화면 상태, 검증 결과, 남은 위험을 보고한다. API 계약과 필수 검증이 확인되어야 완료한다.

## 금지사항

토큰·개인정보의 임의 저장, 운영 주소 하드코딩, 테스트 우회, 요청 범위 밖 대규모 스타일 변경을 금지한다.
