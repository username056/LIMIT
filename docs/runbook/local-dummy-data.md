# 로컬 상품·사용자 더미데이터

로컬 개발 DB에 화면 확인용 회원, 판매자, 상품을 생성할 때만 더미데이터 bootstrap을
활성화한다. 기본값은 비활성화이며 운영 환경에서는 사용하지 않는다.

## 실행

백엔드 실행 환경에 다음 환경변수를 설정한다.

```text
DEMO_DATA_ENABLED=true
DEMO_DATA_PASSWORD=<로컬에서만 사용할 12자 이상의 비밀번호>
DEMO_DATA_USER_COUNT=5
DEMO_DATA_PRODUCTS_PER_USER=4
DEMO_DATA_EMAIL_DOMAIN=limit.local
```

회원 이메일은 `demo01@limit.local` 형식으로 생성된다. 모든 회원은 이메일 인증과 필수 약관
동의가 완료된 상태이며 개인 판매자 프로필이 함께 생성된다.

상품은 판매 중, 숨김, 초안 상태가 섞여 생성된다. 카탈로그와 게시된 체크리스트 템플릿이 먼저
존재해야 하며, 사용할 수 있는 모델이 없으면 상품 생성만 건너뛴다.

같은 설정으로 다시 실행하면 이메일과 상품 제목을 기준으로 기존 데이터를 유지하고 누락된
데이터만 추가한다. 사용자 수나 사용자별 상품 수를 줄여도 기존 데이터는 삭제하지 않는다.
